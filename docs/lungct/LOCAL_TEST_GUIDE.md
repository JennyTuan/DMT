# 肺 CT 工作站：本机测试操作手册

本机已有可导入的**合成 CT 体模**：`D:\STN02\DMT\data\lungct-demo`。它包含 9 层薄层 CT 和 2 层定位像，适合验证导入、质控、阅片、手工标注、复核、快照与导出。它不是患者影像，也不能验证 AI 检出效果。

另有 160 层公开 NLST CT，位于 `D:\STN02\DMT\data\lungct-assets\nlst100206\intake`。这套影像只完成了独立模型资格实验；进入工作站前仍需由实际获授权的检查者核查像素、病例成人胸部及非增强条件。请勿为了导入而勾选尚未完成的确认项。

## 一、启动合成体模演练

在 `D:\STN02\DMT` 打开 PowerShell，运行：

```powershell
.\.venv\Scripts\python.exe -m apps.lungct.server --enable-lungct --data-dir data/lungct-user-demo --allow-root D:\STN02\DMT\data\lungct-demo --demo-directory D:\STN02\DMT\data\lungct-demo
```

保持该窗口运行，在浏览器打开 <http://127.0.0.1:8766>。首页直接显示病例列表，选中演示病例后，底部显示患者与检查信息、图像序列和切片预览；选择可用序列，再点底部“进入分析 →”；无需先填写项目或导入表单。此命令不启用 AI 模型，所有操作只保存在本机 `data/lungct-user-demo`。若没有 `data/lungct-demo`，先运行 `.\.venv\Scripts\python.exe tools/lungct/make_synthetic.py --output data/lungct-demo`；目标目录必须为空。

底部流程栏依次显示“选择检查 → 肺结节分析 → 复核与测量 → 完成与导出”。当前步骤高亮；右侧按钮随状态变化，待复核观察会阻止进入完成步骤。

## 二、从病例列表走完整流程

1. **进入病例**：首页“病例列表”会有 `LUNG-DEMO / R-001`（或该项目下一编号），点击病例行后，底部展开患者信息和两个图像序列。选中 9 层轴位 CT，可在预览图上滚轮翻层，再点底部“进入分析 →”。
2. **查看和定位**：可直接进入 9 层薄层 CT；定位像已被质控拦截。项目和导入信息在“添加病例”弹窗中填写。
3. **阅片定位**：在轴位图上用滚轮翻层。选择“调窗”“平移”或“缩放”后，用左键拖动操作。也可右键拖动平移，用 `Ctrl` 加滚轮围绕指针缩放，或用工具栏的加减按钮调整倍率。选中候选后，“定位候选”会返回原片并居中，保留倍率。“肺窗”和“纵隔窗”切换显示预设，“重置视图”恢复整图。
4. **创建人工草稿**：点“人工复核”，再点“新增结节”，在轴位原片依次落下长径和短径的四个端点。暂时无法测量时，可用“仅标记位置”。观察会以“待复核”出现在右侧。
5. **测量与判定**：选中观察，点“测量双径”或“重测双径”。在默认调窗模式下，也可直接拖动已有径线端点。点“确认”“排除”或“存疑”，按界面提示处理缺测或排除原因。肺部位置、结节类型和修订记录在“观察详情”。已保存的轮廓仍可回查及导出。
6. **完成复核**：处理完所有待复核项后，点底部“完成复核”，在弹窗确认已浏览整例原始影像，再点“完成并冻结”。如需修改，可从冻结快照开启新版本。
7. **导出与回查**：点顶部“导出预览”，查看纳入检查、确认结节和跳过原因，再点“导出研究包到本机”。页面会显示实际输出目录，其中包含 `studies.csv`、`nodules.csv`、`review.json`、`manifest.json`、`dictionary.csv`。在“按导出编号回到原片”输入如 `N-001`，点“回到原始切片”验证追溯。
8. **恢复验证**：刷新页面，或关闭浏览器后重新打开本地地址。病例列表仍在首页，点原病例即可恢复记录。

新导入真实病例时，点列表上方“添加病例”，在弹窗中选项目；没有项目时先创建。填写已批准目录、数据来源和研究来源，完成真实数据确认后导入。新病例会回到首页列表。

## 三、真实 CT 与 AI 测试的边界

公开 NLST 数据已经在本机，但应用导入表单的确认框会登记“授权、脱敏、像素已核查、成人胸部、非增强”均为真。只有实际获授权检查者完成这些核查后，才能把 `--allow-root` 改为 NLST `intake` 目录并在表单中导入它。**不要把合成体模的结果当作 AI 验收。**

核查完成后，可用独立模型环境启动：

```powershell
.\.venv-lungct-model\Scripts\python.exe -m apps.lungct.server --enable-lungct --data-dir data/lungct-real-review --allow-root D:\STN02\DMT\data\lungct-assets\nlst100206\intake --model-bundle data/lungct-assets/monai-0.6.9 --model-profile low-memory
```

真实路径为：建项目 → 填真实来源代号与检查信息 → 导入并选合格序列 → “开始 AI 分析” → 等待运行成功 → “从此运行建立复核分支” → 逐项确认/排除/存疑 → 人工核查候选源片位置 → 完成复核 → 导出。该流程产生研究工作站记录，但不自动构成临床效能结论。现有真实推理记录与尚缺的人工验收项见 [模型可行性记录](model-feasibility.md) 和 [验收记录](acceptance.md)。

关闭工作站：回到启动它的 PowerShell 窗口，按 `Ctrl+C`。
