# 肺结节 CT AI 科研工作站
## 一期产品需求与研发优先级说明书

**交付对象**　Jenny（产品负责人）／Codex（研发团队）　　**版本**　v1.0 · 2026-11-03

> **首发任务：把一次胸部 CT 变成一份可以回到原图核对的结节研究记录。** 研究者能逐项复核 AI 候选、补标漏检、测量、保存，并把多份已复核检查汇成课题数据。不是让 AI 出一份诊断报告。

### 三项决定，作为一期排期依据

| 优先级 | 本期决定 | 判定理由 |
|---|---|---|
| P0 · 必须交付 | 单次 CT 的导入、真实推理、定位、人工复核、测量与科研导出 | 少一个环节，研究者就要回到另一套工具找图、补数或核实来源。 |
| P1 · 验证后增强 | 肺叶辅助定位、三维器官视图、结节轮廓定量、全功能多平面重建 | 先验证定位和定量需求，再承担分割算法、交互和验证成本。 |
| P2 · 后续另立项 | 多期随访、多病种、PET-CT、临床决策及院内生产接入 | 这些任务分别需要纵向真值、专病验证或新的部署与合规条件。 |

### 临床价值优先，第一步验证什么？

**假设：** 与「阅片器＋手工表格」相比，研究者能更快地把一例检查整理成可用记录，同时不增加错侧、错层、漏记与转录错误。先测这件事，不把模型检出率或界面效果当作替代指标。

**使用边界：** 中国地区临床科研人员；单工作站、单操作者、本地离线；输入仅限获准使用的已脱敏数据。界面及导出均标注「仅供科研，不用于临床诊断」。院内科研试点与进入诊疗流程是两次不同的决策。

**阅读路线**　产品与界面 02–04　／　功能优先级 05–06　／　研发契约 07–09　／　验证与执行 10–13

# 谁在什么场景下使用？

**主用户**是整理胸部 CT 回顾性队列的影像科科研医师或有阅片能力的研究者；研究助理可整理已授权数据和输出文件，但不替代医师作影像判断。呼吸科、胸外科课题组是导出数据的协作者。首版不做多人会签或分级账号。

### 产品介入的具体位置

筛查和因其他原因检查均可能产生胸部 CT；两类来源在课题中分别记录为「筛查／非筛查／未知」。国家筛查方案提供临床背景，不把其中的处置阈值移植为本软件自动规则。[S1]

| 环节 | 研究者的动作 | 工作站的反馈或交付物 |
|---|---|---|
| 01 建立课题 | 输入项目简称和操作者研究代号，选择已授权数据 | 建立本地项目；身份用研究代号，不收真实姓名。 |
| 02 选检查 | 导入脱敏 DICOM；核对多序列的层厚、重建信息与预览 | 按检查、序列分组，标出不可用原因；研究者确认唯一分析序列。 |
| 03 运行检测 | 在选定序列上启动检测；也可先走纯人工路径 | 显示任务状态、模型版本、候选数；失败不妨碍人工阅片。 |
| 04 查证病灶 | 点击候选看原片；确认、排除或标为存疑，必要时补标 | 原片、定位小窗、列表同步；AI 原值和人工版本分别保留。 |
| 05 记录测量 | 在选择的原始层面绘制径线，补录类型、侧别和肺叶 | 系统计算物理长度；未知和未测保持为空并带原因，不填 0。 |
| 06 完成与导出 | 核对研究记录，完成病例；选一例或多例导出 | 冻结版本，生成检查表、结节表及溯源文件；能按编号返回原片。 |

### 研发贯穿用例：不是所有候选都要「确认」

虚构病例 R-017：模型给出 3 个候选。研究者确认 1 个、排除 1 个、标记存疑 1 个；另发现并手工补标、确认 1 个。完成时应显示：**模型候选 3，人工新增 1，已确认 2，已排除 1，存疑 1，待复核 0**。默认结节结果表只能有 2 行；存疑及排除在复核记录中可追溯。这个用例贯穿联调、演示和回归测试。

# 中文工作站：主画面给原片

**页面只有三处：**「研究项目／病例队列」负责导入、筛选和批量导出；「肺结节分析」负责选序列、推理和复核；「导出预览」显示纳入数、排除原因、字段字典和目标目录。导出是最后一步，不另造一个报告编辑器。

```text
肺结节分析｜研究项目 / R-017｜当前检查｜仅供科研
┌ 轴位主阅片窗（患者右 R / L 左）  ┬ 患者冠状定位小窗 ┐
│ 原始切片、肺窗、测量和叠加开关   │ 结节列表、复核状态 │
│ 返回选中结节、确认层面            │ 确认／排除／存疑   │
└ 手动添加、测量径线                ┴ 完成复核           ┘
```
布局示意；不作为临床阅片或真实测量的图像。

### 一次点击，三个位置必须一致

点击结节编号后，轴位主窗跳到关联原始切片；右侧列表选中同一编号；患者冠状定位图更新十字线。键盘 ↑／↓ 切换候选，滚轮翻层；输入框有焦点时不拦截方向键。滚动离开病灶层面后标注不得浮在其他层；提供「返回该结节」。隐藏叠加层不删除记录。

### 中文是内容规范，不是翻译皮肤

| 使用位置 | 实际文案／规则 |
|---|---|
| 主导航与按钮 | 「病例队列」「导入检查」「开始 AI 分析」「确认」「排除」「存疑」「手动添加」「完成复核」。图标须有中文提示；状态不能只靠颜色。 |
| 专业术语 | 界面称「纯磨玻璃」「部分实性」「实性」「未判定」；CT、DICOM、AI、mm 保留。MPR 首次显示为「多平面重建（MPR）」；R/L 同时显示「右／左」，均指患者。 |
| 失败与空状态 | 无模型：「未配置检测模型，可继续人工标注」；运行失败：「分析失败，未生成可用结果」；真实成功且为空：「AI 未提示候选，仍需人工浏览」。三者不可混用。 |
| 信息层级 | 默认仅显示编号、侧别／肺叶、类型、长径和复核状态；默认按稳定编号排序，支持按状态筛选；模型分数与版本收在详情，不暗示恶性。设计检查分辨率 1440×900 和 1280×800。 |

# P0：缺一项，不发布 AI 科研版

**优先级解释：** P0 是发版义务，不代表全部同时开发。本表编号 F01–F10 用于需求、工单和测试互相追溯；开发顺序见第 12 页。

| 编号／功能 | 最小可用行为 | 可观察的完成条件 |
|---|---|---|
| F01 项目与队列 | 本地建项目，按病例号、复核状态筛选；保存研究来源与操作者代号 | 重启后继续上次病例；不同课题不混入同一次导出。 |
| F02 导入与选序列 | 读经典单帧胸部 CT DICOM；按检查、序列分组，核验几何与适用范围 | 重复导入不新增；多序列要求确认；定位像、增强或不支持序列不可送检。 |
| F03 基础阅片 | 轴位滚动、窗宽窗位、平移缩放、方向标识、切片索引、叠加开关 | 即使没有模型也能看图；返回结节跳到同一原始切片而非仅同一序号。 |
| F04 真实本地检测 | 一个可复现的模型适配器；显示任务、失败、重试、版本、输入和阈值 | 用真实权重完成至少一例可核查推理；模拟或参考标注不能通过 AI 验收。 |
| F05 直观定位 | 列表、原片、患者冠状定位小窗三方联动；左右取自影像几何 | 已知左右两处目标不互换；不把侧别或精确肺叶从屏幕左右猜出。 |
| F06 人工复核 | 确认、排除、存疑、人工补标、修改、撤回；未决数实时更新 | 重开可恢复；AI 原值不变，原始来源、修改者、时间与原因可查。 |
| F07 研究测量 | 在轴位原片手绘长、短径；人工选结节类型、侧别、肺叶或未知 | 用物理间距计算 mm，保存端点与层面；框宽不冒充径线，缺测不记零。 |
| F08 完成与版本 | 未处理候选阻止完成；存疑可带原因结案；重新编辑产生新版本 | 已导出快照不被改写；无已确认结节也能完成，并保留检查分母。 |
| F09 科研导出 | 病例级和项目级选取已完成检查；中文说明的 CSV 与机器可读 JSON | 同一快照两份输出计数一致；由结节行可在本地回到脱敏原片。 |
| F10 本地保护与留痕 | 默认离线、显式数据来源、导出白名单、科研水印、去标识测试 | 来源未登记或未确认授权不入库；日志不含姓名、原始路径；无遥测和自动上传。 |

> **取舍：** P0 的「测量」指可校核的人工径线；「AI」指自动生成定位候选。首发不承诺自动分割、自动肺叶分类或恶性概率。不能用描边动画替代一笔可追溯的测量。

# P1 与 P2：满足什么条件才开始？

P1 不阻塞 v1.0。P0 技术通过且科研用户试用后，由产品负责人选一项推进。P2 不创建可点击入口，不用虚构数据占位。

| 优先级／方向 | 启动条件 | 后续交付与限制 |
|---|---|---|
| P1-01 肺叶辅助定位、患者三维肺视图 | 对照试用发现二维小窗仍导致找叶慢或错误；有可复核肺叶标签 | 先做肺叶结果可校正与遮罩开关，再比较加三维是否有额外收益；失败退回原片。 |
| P1-02 分割、体积、实性成分 | 有同类目标的轮廓、双读方案；研究课题确需定量 | 显示和编辑掩膜，记录方法；体积以 mm³ 输出。整体结节与实性成分分开验证。 |
| P1-03 多平面精读 | 用户试验显示轴位不能满足具体复核任务 | 增加交互式冠／矢状重建及联动；P0 的只读定位小窗不等于完整 MPR。 |
| P1-04 批量推理与多人复核 | 单例路径稳定且有队列积压，或研究方案需要双读 | 队列调度、权限、阅片者独立性与冲突解决分开立项；禁用自动批量确认。 |
| P2-01 纵向随访 | 有获准的同患者多期检查、跨期对应及未匹配／新发／消失的复核标注 | 先研究双期人工对照，再验证自动匹配；不把两个不同患者拼作随访。 |
| P2-02 多病种／PET-CT | 第二个独立临床任务、数据与任务负责人明确 | 从该任务反推插件边界；不建空的「软组织」「肺炎」或 PET 页面。 |
| P2-03 院内生产／决策 | 明确实际预期用途、医院治理、外部验证及适用监管路径 | PACS/RIS 回写、诊断报告、风险分层、随访建议均需另行评审，不是开关解锁。[S9] |

### 三个最容易做错的替代方案

**先做大屏或多应用导航：** 看起来像平台，但不证明研究者能交付数据。只保留一个可用入口和可替换模型协议。

**先做病灶三维效果：** 视觉定位确实重要，但首发先用患者本人冠状影像验证这个目标；三维能否进一步节省定位时间，要单独对照。

**先收集纵向病例再开工：** 会把单次复核的验证押在另一种数据上。首版保留患者、检查、观察记录三层，不实现跨期病灶身份。

# 从 DICOM 到候选：保住坐标和来源

### 1／输入白名单是首版工程边界，不是临床阈值

P0 仅接收获准、已脱敏的成人胸部非增强 CT，经典单帧、近轴位、均匀采样；首发适配层厚 **>0 且 ≤2.5 mm** 的薄层序列。未压缩 Little Endian 两种常用显式／隐式 VR 纳入测试。定位像、增强型多帧 DICOM（Enhanced CT）及未知传输语法不纳入。核对序列描述、预览、造影信息；缺可靠字段时要求研究者确认是否非增强，无法确认则不送模。此范围不是疾病纳排标准。

按影像方向求切片法向，以位置在法向上的投影排序，不按文件名或 InstanceNumber 排序。校验方向、位置、像素间距及重复／缺层；以灰度斜率与截距换算 HU。方向不可信、明显倾斜或非均匀采样在 P0 **拒绝定量和推理**，给出具体原因。首版工程容差：法向偏离头脚轴 >5°、层间法向差 >1°、层距偏离中位数超过 0.1 mm 与中位层距 5% 两者的较大值 均拦截；记录实际数值与原因。[S6]

### 2／候选基线与坐标回写

优先验证 MONAI `lung_nodule_ct_detection` 的可固定版本（候选：0.6.9）。该研究模型输出检测框、分类标签及分数，不直接提供结节掩膜、肺叶或恶性概率。[S7] 先核权重许可、可获得性、目标机资源和预处理；不能满足时按相同协议替换并登记，不以假结果放行。

| 接口方向 | 约定 |
|---|---|
| 输入 | 一个 series_id；经校验的三维 CT（HU）、源切片映射、方向与间距；模型版本、权重摘要、预处理配置、阈值。权重由获准渠道预置，运行期不联网拉取。 |
| 输出 | run_id、状态、是否完整、耗时；每个候选含不可变编号、中心点和三维框（患者 LPS 毫米）、分数、关联源切片；保存从模型空间返回原图的变换。 |
| 落图 | 转到最近原始层面并保存脱敏源切片引用；校验越界、非数和错序列。合成标记做「原片→重采样→原片」往返测试。模型框只用于定位。 |
| 失败降级 | 任务排队／运行／成功／失败可区分；失败不发布部分结果。内存不足或权重缺失给中文原因及修复入口，允许纯人工工作；禁止默认为成功零候选。 |

### 3／径线的业务含义

P0 仅作研究者在选定轴位原片上的二维测量：先画长径，短径在同层与之垂直，可重新选层重画。两端点用 LPS 毫米保存，长度按物理距离计算，界面保留 1 位小数，内部不提前舍入。短径超过长径则提示重画；不以「框边」或球形估算冒充直径、体积或实性成分大小。

# 导出的每一行，都能回到原片

### 核心实体：跨期先留身份，不提前做匹配

| 实体 | 主键与最小字段／约束 |
|---|---|
| 项目／研究受试者／检查／序列 | project_id → subject_key → study_key → series_key；本地受限映射保存脱敏 Study/Series/SOP UID。subject_key 项目内稳定，不跨项目自动合并。 |
| 分析运行 Run | run_id、series_key、输入哈希、权重／预处理／阈值／软件版本、状态与错误码；纯人工路径无 run_id，另记 analysis_mode。 |
| 单次观察 Finding | finding_id 仅表示本次序列上的观察，不是跨期病灶 ID。来源 ai 或 manual；原始候选不可变，保留中心点、切片键、模型框或人工初始点。 |
| 复核修订 Revision | revision_id、finding_id、前版本、研究者代号、时间、动作、理由、最终位置、侧别、肺叶、类型、测量端点与值；追加写，不物理删除。 |
| 病例快照／导出清单 | snapshot_id 绑定序列、活动运行或人工模式及全部采用的修订；export_id 引用快照集合、字段字典版本与文件校验和。重新导出不覆盖旧包。 |

### 一次导出，一个可复核的研究包

| 文件 | 每一行代表什么 | 必备内容 |
|---|---|---|
| studies.csv | 一次已完成检查的一个指定快照 | 项目、研究病例号、检查／序列键、快照、分析方式、运行状态、原始候选数、确认／排除／存疑／人工新增数；零确认检查也有一行。 |
| nodules.csv | 该快照内一个已确认结节 | 稳定结节号、病例和序列键、切片键、LPS 中心、来源、侧别、肺叶、类型、长短径 mm、缺测原因、修订号。存疑不混入确认行。 |
| review.json | 入选病例的完整复核链 | 原始候选、人工增补、存疑与排除、修改前后值、操作者研究代号、版本。字段白名单；不附图像、不收自由病史。 |
| manifest.json／dictionary.csv | 一次导出的可重放清单／字段字典 | 数据集版本、纳入检查和快照列表、模型或人工模式、阈值、软件版本、样本计数与内容文件 SHA-256；英文字段键对应中文释义、单位、枚举和空值。 |

**格式与回查：** CSV 为 UTF-8 BOM；小数用点、空值留空，JSON 使用 null；时间带时区。应用内支持用项目＋检查＋结节编号查找原始切片；切片键仅在同一脱敏库解析，并非全院患者号。示例：R-017 的检查表 1 行、结节表 2 行，复核链保留 4 个观察对象。

# 状态、写入与冲突：不要覆盖研究证据

以下为逻辑接口；沿用仓库既有 HTTP、IPC 或服务层实现，不要求改栈。字段名与语义应一致，序列、运行、快照均校验所属项目。为接口提供带版本的 schema 和合成测试样本。

| 操作 | 输入 → 输出 | 约束与失败行为 |
|---|---|---|
| importStudy／selectSeries | 本地许可目录＋来源 → 检查／候选序列和质控项；确认 → series_key | 同一项目同一 UID 且内容一致去重；同 UID 不同内容隔离报错。不修改原始 DICOM。 |
| startRun／getRun | 序列键＋模型配置＋请求键 → 运行 ID／状态／候选 | 重复提交同一请求不重复推理；显式重算创建新运行。旧版原始结果不可变。 |
| addFinding／reviseFinding | 人工点／已有观察＋新值＋理由＋预期修订号 → 新修订 | 旧修订号写入时拒绝并提示刷新；撤销以反向修订实现，审计可回放。 |
| completeCase／reopenCase | 当前修订集合＋操作者确认 → 冻结快照／新草稿 | 存在待复核项不能完成；完成无已确认项时需明确确认。重开复制为新草稿，旧快照可查。 |
| exportSnapshots | 同项目已完成快照集合＋字段版本 → 研究包、摘要和错误列表 | 初始默认每例最新已完成一版；预览列出跳过数。不导出草稿；落盘失败无半成品成功提示。 |

### 两套状态，不能用同一个「已完成」代替

**运行状态**：未运行 → 排队 → 运行中 → 成功／失败。**观察状态**：待复核 → 已确认／已排除／存疑；后续修改须有新修订。人工补标同样进入待复核，确认后才计入结果。**病例状态**单独记录为草稿／复核中／已完成。

**完成条件：** 已选择有效序列；研究者确认已浏览整例；全部候选均处理；存疑、排除和缺测各按结构化字典记录原因。已确认项要么存长径，要么显式标为未测并说明。肺叶／类型不确定允许填「未判定」，不迫使研究者猜。

**重跑策略：** 编辑开始后会话绑定原运行。重算仅新增运行分支；不自动合并、匹配或覆盖已复核记录。用户可继续旧草稿，或明确从新结果开新草稿并按新分支复核。纯人工完成亦保留此前失败记录；候选数无定义填空，不写成真实检测的零。

### 各数据源分别回答什么问题？

| 来源 | 用在何处 | 禁止推论 |
|---|---|---|

### 怎样做一次有用的科研用户试验？

拟招募 **5 位**目标研究者，准备 **12 例**获准、难度平衡的检查，含低候选量、多候选、疑似假阳性及需人工补标的样本。每人用旧流程和工作站各做 6 例且不重做同例；病例在不同研究者之间交叉分配，平衡工具、顺序及经验。旧流程定义为「相同源像＋常用阅片器＋统一字段表」，计时都从打开病例到产出完整研究记录。

**主要指标：** 每人两套流程的每例完成时间中位数，以「(旧−新)／旧」计算，再汇总 5 人的中位变化。**建议继续迭代线：** 中位耗时下降 ≥20%，且至少 4/5 人能独立完成定位、补标和导出。都是拟定目标，不是已测结果。

**安全与质量：** 独立阅片者复核错侧、错层、错病例和漏记；歧义由第二人裁定。错侧／错层／错病例应为 0；对照两流程的关键字段完整率、漏记数量与假阳性处理量，质量变差不以节时抵消。分开记录定位用时和导出整理用时，以判断应改模型还是交互。样本仅用于形成性评价，不作临床有效性结论。

**算法另报：** 锁定模型、阈值和患者级划分，记录每层样本数；按官方 FROC 计算 1/8、1/4、1/2、1、2、4、8 个假阳性／扫描的灵敏度及其均值，另报固定阈值下的灵敏度和 FP/scan。[S5] 无可核实独立样本时只报技术复现，不发布外部性能。候选被人工排除的比例不是有真值的假阳性率。
