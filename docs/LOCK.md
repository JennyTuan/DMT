# DMT · 产品锁定（LOCK）

锁定日期：2026-11-02（Jenny + CT 设计辩论：产品 / 方案 / 合规质量 · Lumi 收口）

## 命名

| 层级 | 名称 | 含义 |
| --- | --- | --- |
| **伞仓 / 产品线** | **DMT**（本仓库） | 多模态随访产品线的**空伞**；仅作仓名与目录根 |
| **第一模块** | **`petfollow-lymphoma`** | 淋巴瘤 PET-CT 治疗后代谢随访 · 院内试用原型 |

**硬规则**：不得用「DMT」二字对外或对内宣称「多模态后处理平台 / 智能诊断平台 / 已支持多模态全家桶」。后续模态另开模块、另开刀、另命名；第一刀仍是单病种单模态。

本仓为**独立新仓**：不继承、不 submodule、不运行时依赖 `longitudinal-imaging` 或冠脉刀。可借鉴 Finding / proposed 思路，数据契约在本仓重写最小子集。

## 做什么（两周）

- **病种**：淋巴瘤 · 治疗后代谢随访（门诊对照）——单一索引病种
- **形态**：院内试用 / 科研原型；暂不真实 NMPA 注册申报
- **全流程 MVP**（后续包实现）：导入 PET+CT → 半自动 ROI → SUVmax + CT 最长径 → 关联上次检查 → 可改留痕 → 描述性报告草稿
- **界面常驻**：`原型·不可用于临床诊疗决策`（导出/截图同等声明）

## 不做什么（禁区，未重开前永久）

- 恶性判定 / 「诊断结论」字段
- 自动 Deauville / Lugano 分级
- 「完全/部分代谢缓解」等疗效结论字段
- 筛查或分期决策主叙事
- 多癌种 / 泛肿瘤壳、多模态平台话术
- 真实三类注册材料包、已注册/可替代在用工作站暗示
- 与冠脉/肺结节旧仓共用运行时或偷渡旧叙事

## 合规底线（院内试用）

1. 每屏 / 导出带原型标识  
2. 关键量测可改、可回看留痕；不确定进 `needs_review`，不硬出终数
