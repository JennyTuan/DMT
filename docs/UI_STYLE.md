- 禁借 DMT 字样做全家桶导航（多病种、多模态应用超市）

## 1. 参考方向（学气质，不抄皮）

**要对齐的气质（国产影像工作站）**

- 深色 / 深灰临床底色，低饱和控件  
- **视口为主、列表为辅**：中央多视口（PET / CT / 融合），右侧或下方病灶与测量列表  
- 顶栏：患者/检查切换、先验对照入口、原型横幅  
- 信息密度高：数字（SUVmax、最长径 mm）一眼可见、可点改  
- 工具是「ROI / 测径 / 留痕 / 导出草稿」，不是聊天助手

**公开参考（结构学习用，禁止复制商标/图标/启动画面）**

- 联影医学影像软件产品页（uWS / Image Fusion 能力描述）：https://global.united-imaging.com/en/product-service/software-and-solution/software  
- 联影智能 PET/CT 分析相关公开介绍（看挂片+列表信息架构，不抄品牌）：https://www.uii-ai.com/article/104.html  

截图入库规则：只用**自有拍摄/公开新闻配图经法务允许**的参考图放到 `docs/refs/`，文件名勿含竞品商标；BRIEF 里用「国产 PET-CT 工作站·视口+右侧列表」文字描述即可开工。

## 3. 视觉硬规则

| 要 | 不要 |
| --- | --- |
| 深色临床壳、细分割线、等宽数字 | 大留白营销落地页风 |
| 顶栏常驻原型黄/橙条 | 渐变紫、霓虹、玻璃拟态「AI 感」 |
| 列表行高紧凑、选中高亮 | 对话气泡 / Copilot 侧栏当主交互 |
| 中文优先、控件短标签 | 英文空泛 Slogan（Intelligent / Next-gen） |
| 失败/未校正 → `needs_review` 文案 | 热图铺满无列表、无测径入口 |
