# DMT · UI 方向锁定（首模块 `petfollow-lymphoma`）

锁定日期：2026-11-02（Jenny 方向）

> Pack1 **不要求实现任何 UI**。本文锁定后续 UI 包的审美与信息架构，防止 Codex 自行发明 Silicon Valley AI chrome。

## 要对齐的感觉

- **国内医学影像工作站**：信息密度高、面板分区清楚、工具栏 + 多视口（PET / CT / 融合）为主轴。
- 参考气质：联影（United Imaging）等国产临床工作站——**灰度/临床中性色、密而不乱、可读优先**。
- **不要**：海外 glossy AI demo（大圆角卡片、霓虹渐变、营销落地页风、过空的「智能助手」聊天壳）。

## 明确禁止

- 抄袭或仿冒联影（或其他厂商）的**商标、Logo、图标集、启动画面、受保护视觉识别**。
- 成品看起来像「联影换皮」或带厂商暗示的克隆。
- 用 DMT / 多模态字样在 UI 上做成「平台导航全家桶」；第一模块只呈现淋巴瘤 PET 随访工作流。
- 省略常驻横幅：`原型·不可用于临床诊疗决策`（深色警示条，导出/截图同等文案）。

## 布局原则（后续 UI 包）

1. **视口优先**：主区给影像（CT / PET / Fusion）；测量表与病灶列表为侧栏或底栏，可折叠但不默认藏空。
2. **密度**：一屏可见关键测量（SUVmax、最长径、先验对照），少用大留白英雄区。
3. **色板**：深灰/中灰背景 + 高对比正文；强调色仅用于状态（`proposed` / `needs_review` / 错误拦截），避免彩虹仪表盘。
4. **状态可见**：每个 Finding / Measurement 的 `ProposedState` 用小徽章，不用弹窗海洋。
5. **禁字段不画控件**：无 Deauville、Lugano、缓解结论、恶性判定入口——连 disabled 灰按钮都不要，避免误导。

## 产品验收门（后续 UI 包；来自 @产品）

UI 包交付时，产品侧按此打假（Pack01 无 UI，仅预读）：

1. **融合能看**：PET / CT / 融合视口可用，信息密度够，不靠营销大卡片撑场面  
2. **条目能改**：SUVmax、CT 最长径可编辑；每次改动可回看留痕  
3. **对照能链**：能关联上次检查 / 病灶条目（先验链接可见）  
4. **草稿能出**：描述性报告草稿可编辑导出；常驻 `原型·不可用于临床诊疗决策`  
5. **无结论控件**：界面不出现 Deauville / Lugano / 缓解结论 / 恶性判定 / 「诊断结论」字段或入口  

未过以上任一条 → 产品打回，不得宣称「院内正式诊疗可用」。
