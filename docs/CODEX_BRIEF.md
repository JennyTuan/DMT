## 1. 目标（两周院内试用）

全流程跑通：

**导入 PET+CT → 半自动 ROI → SUVmax + CT 最长径 → 关联上次检查 → 可改留痕 → 描述性报告草稿**

每屏 / 导出物常驻文案：`原型·不可用于临床诊疗决策`。

## 2. 定位与禁区

**是**

- 单病种：淋巴瘤治疗后代谢随访对照工具
- 单模态组合：FDG PET-CT（PET + 同检 CT）
- 交付物：可编辑测量条目 + 前后对照 + 描述性草稿（proposed）
- 运行环境：单机科研/试用（RTX 3060）

**不是 / 禁止实现或文案出现**

- 多模态诊断平台、多癌种壳、筛查主叙事
- 自动 Deauville / Lugano / 「完全|部分代谢缓解」结论字段
- 恶性判定、手术规划、辅助诊断声称
- 真实 NMPA 注册材料包、与 `longitudinal-imaging` / 冠脉仓代码或 submodule 绑定

## 4. 验收总门（产品 + 合规）

1. 全流程可跑通；每屏有原型标识；导出带同等声明  
2. 关键量测可改、可回看留痕；不确定不硬出终值  
3. 无自动恶性/缓解分级/诊断结论字段  
4. 范围仅淋巴瘤 PET 随访；不扩第二病种或第二模态产品叙事
