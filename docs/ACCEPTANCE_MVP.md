# 院内试用原型 · 人工验收清单

**原型·不可用于临床诊疗决策**

对象为淋巴瘤 FDG PET-CT 随访原型。请用单独的本地示意工作目录验收。以下方框留给实际操作者勾选；自动测试结果另记。记录提交号、操作者、日期、示意检查 ID 和失败步骤。截图保留完整窗口及顶部原型条。

| 核对 | 操作 | 预期结果与截图位置 |
| --- | --- | --- |
| [ ] 1. 载入 | 按根 README 启动 `--demo`，在「切至示意基线」与「切至示意随访」间切换，最后停在随访。 | 同一患者代号，两次检查时间不同。「示意数据」徽标、PET/CT 双视口、原型条均可见。截图 A 取整个工作站。 |
| [ ] 2. 画 ROI | 在随访检查选「＋ 新病灶」。PET 第 11 层、65% 阈值点中央稍偏右的亮灶（原图 `x=104, y=90`），填“纵隔验收条目”，保存 ROI。 | 轮廓与右侧量测同屏。示意 SUVmax 约 9.35、CT 最长径估计约 12.90 mm，量测状态为待确认。 |
| [ ] 3. 修订与留痕 | 对该病灶调阈值或涂改轮廓，再保存。双击一项量测，填写新数值和修改依据。打开「数值留痕」。 | 可查自动值、ROI 重算和人工改数的前后值、时间、操作方及 ROI 版本。状态转换记录独立保留。截图 B 取数值留痕窗口与原型条。 |
| [ ] 4. 选先验 | 在顶栏「关联上次」先清除，再选同一示意患者较早的基线检查。打开「前后对照」。 | 只能选择同患者的较早检查。未配对条目的差值为 `—`。「质量门」列出 `TRACK_INCOMPLETE` 提醒。 |
| [ ] 5. 配对与跳过 | 选验收条目，选上次病灶，点「指定配对」。对另一个未配对的本次条目点「跳过本次配对」。再试「取消跳过」，确认提醒恢复，最后按验收选择配对或跳过。 | 两侧已配对病灶共享跟踪号，SUVmax、最长径都列出本次、上次及差值。显式跳过仅作用于此次先验关联，不改变数值或病灶状态。截图 C 取前后对照区。 |
| [ ] 6. 核对门控 | 点顶栏「质量门」，选中任意一行查看详情。 | 有门控编号、级别、目标、原因、动作。能区分“符合”“未检查”“提醒”“需复核”“阻断”。保存目录中可读到本次检查的结构化快照。截图 D 取完整质量门窗口。 |
| [ ] 7. 草稿与导出 | 打开「报告草稿」，写一段部位和层面的描述，点「从当前量测重新生成」，保存，导出到新的 Markdown 文件名，再用文本编辑器打开。 | 手写段落保留，文件含检查、先验、两侧量测和状态。首行严格为原型声明。未跳过的未配对条目会在导出前提醒。截图 E 取草稿窗口及导出文件首行。 |
| [ ] 8. 实测复核路径 | 在仓库根目录运行下方命令生成旧版计数示例，导入生成的 `data/fixtures/petfollow-demo-v1`，按第 2 步画 ROI。 | `SUV_META_MISSING` 给出复核原因，自动 SUV 为空。可独立计算的 CT 径值保留，量测转为 `needs_review`。反复打开质量门不重复追加状态转换。截图 F 取失败行及目标。 |
| [ ] 9. 实测阻断路径 | 在示意草稿描述内临时键入测试词“完全代谢缓解”，尝试导出，再删去并重新生成。在一次性示意目录中还可关闭草稿，保留备份，仅删去已保存草稿 JSON 的 `generated` 文本首行原型句，再打开草稿尝试导出。 | 前者红色显示 `BANNED_TERMS`，后者显示 `PROTOTYPE_BANNER`。两者均不产生新导出文件。修正或重新生成后可恢复。截图 G 取门控编号和阻断原因。 |
| [ ] 10. 范围与复核 | 对照全部截图、导出、数值史和状态机记录，逐条核对[残留风险条件](RESIDUAL_RISK.md)。 | 在单机上完成上述路径。程序没有自动给出终态或结论。每项失败均需记录，不得用其他步骤通过来抵消。 |
