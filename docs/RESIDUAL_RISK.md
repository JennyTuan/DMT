# 院内试用残留风险可接受条件

**原型·不可用于临床诊疗决策**

仅当下列六项**全部成立并经人工核对**时，本原型在限定科室、有人值守的科研或院内试用中，残留风险才视为可接受。工具记录本地数据与文本是否满足规则；试用条件由产品与合规质量人员对照实机和导出物确认。

| 项 | 必须成立的条件 | 核对证据 |
| --- | --- | --- |
| 1 | 每个工作屏、草稿与导出物常驻或保留完整原型声明。所有用途说明限于科研及院内试用。 | 工作站、质量门和草稿窗口截图，导出文件首行。 |
| 2 | 操作者能人工改 ROI 和量测，能回看数值史、ROI 版本和状态机审计。不确定结果留空或标明待复核，不能作为终值。 | 实做一次轮廓修订、一次改数，核对原值、新值、依据、时间及状态记录。 |
| 3 | 缺衰减校正、定量资料不全或层面对齐失败时，受影响量测进入 `needs_review`。程序不得自动接受或拒绝量测。 | 失败门控编号、具体原因、量测当前状态，以及合法且不重复的状态转换。 |
| 4 | 没有自动疗效、Deauville、Lugano 或恶性判定字段。草稿及导出中的禁用表述由禁词门阻断。 | 检查字段与报告控件，实测命中禁词时无导出文件。 |
| 5 | 流程只用于淋巴瘤 FDG PET-CT 随访对照。示意数据在界面有清楚徽标，草稿明确数据来源。 | 核对本次和先验检查标识、来源、原型名称与报告中的示意标记。 |
| 6 | 数据处理和推理均在本机完成，无云推理依赖。操作者了解合成数据只能演示流程，不能代表院内设备、实际影像质量或真实病灶分布。 | 依赖安装后离线运行示意全流程，由实际操作者记录知悉情况。 |

任一条件被产品改动削弱，**本包验收失败，须重新开启合规质量验收**。若现有证据不足，记为待核对。实机点击步骤与记录栏见[人工验收清单](ACCEPTANCE_MVP.md)。
