# 淋巴瘤 PET 随访原型 · 网页端首版

## 决定

研发阶段以浏览器作为操作入口。先在本机启动网页服务，沿用现有 DICOM 解析、SUV 校验、ROI、配对、留痕和报告草稿规则；网页端不依赖桌面窗口。服务只监听 `127.0.0.1`，避免在没有身份验证和医院网络方案前开放患者数据。

本版以合成双期病例跑通：选择检查 → PET/CT 阅片 → PET 种子 ROI → 保存与量测 → 基线/本次人工配对 → 描述性报告草稿。网页「导入」可从浏览器选择同检 PET/CT 文件夹，影像只传到本机 `127.0.0.1` 服务并存于仓库 `data/uploads/`；另可通过本机 API 导入已有 `data/` 目录。原有桌面程序保留为历史实现，不再作为研发主入口。

## 图像浏览布局与工具

视觉参照见 [网页工作站主屏概念图](web-workstation-concept.png)。采用连续平铺视口和表格，不使用卡片式仪表盘。工作台背景 `#1B2024`，影像背景 `#090B0D`，工具栏 `#252B30`，分隔线 `#3A444A`；正文 `#E5EBEC`，次级文字约 `#B5C1C5`。交互和选中使用蓝灰 `#7899AD`，ROI 轮廓保留青绿 `#53E2D5`，待复核使用琥珀 `#D4A460`，错误使用柔红 `#D17A73`；状态同时写明文字。标题 17px，工具与表格 13px，关键量测 15px，影像角标 12px，底部状态 11px。控件直角、行高约 31–32px，数值使用等宽数字。

概念图中贯穿视口的十字线只是早期视觉探索，不代表现有能力。当前网页只在点选或回看 PET ROI 时，以短蓝灰定位标记表示种子点；不画跨视口参考线。完整十字参考线须在 DICOM 空间映射和联动验证后再加入。

布局模板在同一工作台中切换，不重新加载病例：

| 模板 | 用途 | 视口 |
| --- | --- | --- |
| 双期四格（默认） | 基线与本次的 PET、CT 纵向对照 | 基线 PET、本次 PET、基线 CT、本次 CT |
| 双期双格 | 重点比较代谢变化 | 基线 PET、本次 PET |
| 本次双格 | 本次勾画与 CT 核对 | 本次 PET、本次 CT |
| 单视口 | 精细勾画和读片 | 选中的 PET 或 CT |

当前工具：独立切层与鼠标滚轮、布局切换、PET/CT 显示窗宽窗位或强度范围、缩放和平移、复位、PET 种子阈值 ROI、量测值人工修订与留痕、人工跨期病灶配对、SUVmax 绝对值及百分比变化、描述性草稿。未执行单点对齐时，同步切层仅按层数比例导航；两期 PET 各点一次同一标志后，使用 DICOM 患者坐标计算三维平移量，并按物理切片位置同步翻层。单点平移仍需人工核对解剖，不等同于非刚性配准。

| 工具组 | 首版已接通 | 后续验证后加入 |
| --- | --- | --- |
| 浏览 | 病例/基线切换、四种挂片、独立或比例切层、两期 PET 单点平移对齐后的物理位置翻层、活动视口 | 缩略图导航、完整三平面解剖位置联动、挂片模板保存 |

| 空间重建 | 原始轴位 PET 与 CT 独立显示 | DICOM 几何校验后的融合、冠矢状 MPR、全身 MIP、局部放大镜 |
| 标注量测 | 当前 PET 单层种子阈值 ROI、SUVmax 与 CT 最长径估计、人工修订及留痕 | 3D VOI、笔刷/擦除、CT 双径与 SPD、SUVmean/peak、距离/角度、参考组织 VOI |

工具栏只摆放已接通的操作；未验证的功能先留在此清单，不画成假按钮。

后续需单列验证：以 DICOM 患者坐标做 PET/CT 融合与跨期位置联动、冠矢状 MPR、全身 MIP、测径线工具、截图/DICOM Key Image。未实现前不在网页上显示可操作入口。DICOM 的图像位置、方向和像素间距共同决定空间映射，不能用相同层号替代。[DICOM Image Plane](https://dicom.nema.org/medical/dicom/current/output/chtml/part03/sect_C.7.6.2.html)

## 临床与数据边界

- 浏览器底部状态栏以普通状态文字显示「原型·不可用于临床诊疗决策」和数据性质，不在顶部设置提示横幅。导出内容保留同样声明。合成病例另外标「示意数据」。
- 不生成 Deauville、Lugano、恶性或缓解结论；PDF 中的这些设想待临床验证与现有产品锁定另行调整。
- 缺失 SUV 必需参数时保持空值和复核状态，不补造默认剂量。
- 同步翻层只是导航；不声称全身空间配准或自动病灶对应。病灶配对由人确认。

## 验收口径

先做探索性验证，不预填临床基线或 100% 正确率。记录每例及每个病灶的耗时、配对是否正确、无法判断率、量测和草稿差错。标准测试数据验证 SUV 算法，临床图像在相同图像及 ROI 口径下另做一致性分析。
