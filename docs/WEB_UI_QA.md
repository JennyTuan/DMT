# 网页端视觉与交互核对 · 2026-11-03

视觉参照：`docs/web-workstation-concept.png`。实际页面在 Codex 内置浏览器以 1544×900 默认视口和 800×900 窄视口核查。

| 核对点 | 实际结果 |
| --- | --- |
| 顶部结构 | 无原型警告横幅；50px 检查头栏、45px 连续工具栏 |
| 布局 | 四格、双期 PET 双格、本次 PET/CT 双格、单视口均在同页切换 |
| 色彩与容器 | 深石墨工作台、黑色影像画布、细分隔线；蓝灰用于交互与选中，青绿用于 ROI 轮廓，琥珀用于待复核；无卡片或阴影 |
| 字体 | 标题 17px、工具/表格 13px、量测 15px、影像角标 12px、状态 11px；数字等宽 |
| 核心交互 | 浏览器内验证双期布局切换、病灶回看、人工配对后差值更新、报告草稿入口；API 验证 ROI 与文件夹上传 |
| 窄屏 | 800px 下视口保持 2×2，侧栏移至影像下方，表格独立横向滚动 |

与概念图的有意差异：概念图使用融合影像和三条示意病灶；当前真实实现仅显示独立 PET/CT 原始轴位，合成数据只有一条已保存病灶。融合必须先验证 DICOM 空间几何；当前没有将示意图中的 SUVmean、体积、3D VOI 或自动诊断标签做成假控件。

UI 评审修订：概念图的全幅十字线容易暗示已实现空间联动，当前版本改为 ROI 种子点周围的短蓝灰标记；全幅参考线留到几何映射验证后。
