# Phase 1 网页工作站实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在网页端实现 V2.0 修订版规划书的 Phase 1 六项能力，并用真实双期病例完成可追溯验证。

**Architecture:** 延用现有 Flask 服务与 React 工作台；DICOM 解析、空间几何、定量和报告规则放在独立 Python 模块，网页只呈现数据和显式人工确认。所有临床候选提示必须显示依据、缺失条件和确认人，不自动写成最终结论。

**Tech Stack:** Python、pydicom、NumPy、Flask、React、TypeScript。

**Spec:** `C:/Users/STN/Downloads/PET-CT淋巴瘤专病工作站产品规划书 (V2.0 修订版).pdf`，第 4 页 Phase 1，第 6–7 页验收指标。

## Global Constraints

- 交付形态为网页端；研发服务当前只监听 `127.0.0.1`。
- 不把按层数比例翻层称为空间配准。
- 缺失或无效剂量等参数时，正式 SUV 必须为空；人工补录需双源核对、留痕、显著标识。
- Deauville 和 Lugano 为系统候选提示，最终评分与结论由医生显式确认。
- 真实病例需要可追溯来源、合法访问权、双期 PET/CT、定量元数据和独立专家金标准。

## Review Focus

- 多床位、多序列、不同方向或切片间距的 DICOM 不得被误当为单一规则体积。
- 跨期缺少可用几何或人工标志点时，不得显示“已对齐”。
- 基线 SUV 为零或缺失时，百分比变化不得除零或填造数值。
- ROI 与内参的坐标、单位和时间点必须随检查、序列及版本一起保存。
- 导出必须核对当前检查、人工确认状态与数据来源，不得沿用旧草稿。

## Tasks

### 1. 真实病例与验收清单

- [ ] 从官方影像库核对候选集合的授权、双期 PET/CT 数量、DICOM 元数据和下载方式，保存来源清单。
- [ ] 取得 20 例合格的基线＋中期病例及每例 3–5 个专家确认靶灶；缺授权或专家金标准时明确记录阻塞项。
- [ ] 运行导入与缺失参数筛查，冻结可复现的病例清单和版本。

### 2. 数据与定量底座

- [ ] 增强同一检查多序列选择、空间几何校验和原始浓度显示；测试错误序列、缺片、单位与方向冲突。
- [ ] 实现双源核对的人工参数补录及审计记录；测试补录前后、撤销和导出水印。
- [ ] 用标准模体和对照工作站验证 SUVmax/SUVmean，独立记录误差与缺参拦截率。

### 3. 跨期空间阅片

- [ ] 建立 DICOM 患者坐标到体素坐标的映射和单点 3D 平移校准，测试不同原点、间距、方向。
- [ ] 实现单期 1＋3、双期 2×4 的轴/冠/矢/MIP 视口，以及对齐后的同步定位。
- [ ] 对没有几何数据的病例保留独立浏览，但禁用空间联动并显示原因。

### 4. 病灶、内参与候选活检证据

- [ ] 实现三维 41% SUVmax VOI、极值坐标和可复核编辑；测试连通性、坏死区与生理摄取误选。
- [ ] 实现血池圆柱、肝脏 3 cm 球形 VOI，显示并保存 SUVmax/SUVmean。
- [ ] 实现 CT 长短径、SPD、融合透明度/轮廓切换，以及候选靶点体表与血管距离证据图。

### 5. 跨期书签、辅助判读和报告

- [ ] 保存基线 3D 书签快照，人工关联本次病灶；计算 ΔSUVmax(%)、ΔSPD(%) 并处理零基线与缺失值。
- [ ] 基于内参与变化趋势生成可解释的 Deauville 候选提示，医生显式确认 1–5/X 与 Lugano 候选分类。
- [ ] 生成结构化对比文本、Key Image，并验证复制/导入 RIS 的目标接口和失败回退。

### 6. 临床验收

- [ ] 两名核医学医师按第 6–7 页协议在 20 例上盲测，对照传统流程并记录耗时与配对金标准。
- [ ] 统计配对正确率、SUV 一致性、缺参拦截率、报告耗时与抄写错误；不预设结果达标。
- [ ] 汇总失败病例、修订与复测证据，再判断是否达到 Phase 1 验收。
